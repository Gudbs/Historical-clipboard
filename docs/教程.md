# ClipHistory 剪贴板历史工具 · 零基础分步教程

> 本教程面向**完全不懂代码**的你：每一步都写明「点哪里、输入什么命令、会看到什么」。
> 跟着做，最终能把这个软件打包成安装包，双击即可安装使用。
> 全程大概需要 15~30 分钟。

---

## 先了解一下

- **这个软件做什么？** 自动记录你复制过的文本、截图、图片、复制的文件，随时可以找回，点击一下就能重新复制。数据只存在你电脑里，**完全不上传网络**。
- **你需要准备什么？** 一台 Windows 电脑 + 约 1GB 硬盘空间。
- **学完能得到什么？** 一个 `ClipHistory-Setup-1.0.0.exe` 安装包，双击安装后就能长期使用，还能开机自启、后台托盘常驻。

---

## 第 1 步：安装 Node.js（编程运行环境）

这个软件需要 Node.js 才能「运行源码」和「打包成 exe」，装一次就行。

1. 打开浏览器，进入官网：**https://nodejs.org/zh-cn**
2. 页面中间有一个绿色的下载按钮，写着 **「LTS」**（长期支持版），点击下载 **Windows 安装包**（文件名类似 `node-v20.x.x-x64.msi`）。
3. 下载完成后，**双击** 这个 `.msi` 文件。
4. 安装向导弹出后，一路点 **「Next（下一步）」**，最后点 **「Install（安装）」**，等待安装完成，点 **「Finish（完成）」**。中间所有选项都不用改。
5. 验证是否装好：
   - 按下键盘 **`Win` 键**（左下角带窗口图标的键），输入 `cmd`，回车，打开「命令提示符」窗口（黑色窗口）。
   - 在里面输入下面这行命令，然后按回车：
     ```
     node -v
     ```
   - 如果看到 `v18`、`v20`、`v22` 等以 `v` 开头的版本号，说明安装成功 ✅
   - 如果提示「不是内部或外部命令」，说明没有生效：把黑色窗口**关掉重新打开**再试一次。

## 第 2 步：拿到项目源码

项目源码已经在你的电脑里了（就是我现在所在的这个文件夹）。

> 💡 **建议（很重要）**：把这个文件夹**复制**到一个**纯英文、没有空格的路径**下再操作，例如 `C:\clipboard-history`。
> 方法：全选项目文件夹里的所有内容 → 复制 → 到 `C:\` 下新建一个 `clipboard-history` 文件夹 → 粘贴。
> 如果路径里有中文或空格，极少数电脑在打包时可能会报错，换成英文路径最稳妥。

## 第 3 步：配置国内下载加速（已配好，跳过即可）

项目里已经有一个 `.npmrc` 文件，里面配置了国内镜像（淘宝源），这样下载依赖和 Electron 会快很多。
**你不需要做任何操作。** 看到这里直接进入下一步即可。

> 小提示：Windows 会默认隐藏 `.npmrc` 这种以点开头的文件，看不到是正常的，不用管它。

## 第 4 步：安装依赖（下载运行所需的零件）

1. 打开项目文件夹，在文件夹地址栏里输入 `cmd` 并按回车（会直接在该目录打开黑色命令行窗口）。
2. 输入下面命令，按回车，然后**耐心等待**（一般 1~5 分钟）：
   ```
   npm install
   ```
3. 看到类似 `added 311 packages in 35s` 的字样，就成功了 ✅
4. 如果中间报错，先重新执行一次 `npm install` 试试；仍不行请看文末「常见问题」。
   （看到 `npm warn ... electron_mirror ...` 之类的黄字警告是**正常现象**，不影响使用，忽略即可。）

---

## 第 5 步：本地启动测试（先跑起来看看）

1. 在同一命令行窗口输入：
   ```
   npm start
   ```
2. 稍等 2~3 秒，会**弹出软件窗口**。你现在就可以试试：
   - 随便复制一段文字 → 软件里出现一张文字卡片（显示时间和预览）；
   - 按下 `Win + Shift + S` 截图并复制 → 出现一张图片卡片（带缩略图）；
   - 在文件管理器里选中几个文件按 `Ctrl+C` → 出现一张「文件」卡片；
   - 点一下任意卡片 → 到别处 `Ctrl+V` 就能粘贴出来。
3. 测试完怎么退出？点窗口右上角 **✕** 并不会退出，而是**最小化到右下角托盘**（屏幕右下角时间旁边会有个小图标）。右键那个图标 → 点「退出」才真正关闭。
4. 停止命令行：回到命令行窗口按 `Ctrl + C` 两次（或直接关掉窗口）。

---

## 第 6 步：打包成 Windows 安装包（重点）

1. 确保第 5 步的软件窗口已经关闭（否则文件被占用可能打包失败）。
2. 在命令行窗口输入：
   ```
   npm run dist
   ```
3. 耐心等待 **3~10 分钟**（第一次要下载打包工具，之后会快很多）。期间命令行会滚动很多文字，**不要关闭窗口**。
4. 看到 `Build completed` 或最后出现安装包路径，就成功了 ✅
5. 打开项目里的 **`dist`** 文件夹，会看到安装包：
   ```
   dist\ClipHistory-Setup-1.0.0.exe
   ```
   （还可能有 `win-unpacked` 文件夹，那是免安装版本，里面也有 `ClipHistory.exe` 可以直接双击运行。）

## 第 7 步：安装并运行

1. **双击** `ClipHistory-Setup-1.0.0.exe`。
2. 如果弹出 **「Windows 已保护你的电脑」** 蓝色提示：这是正常现象，因为软件没有微软的数字签名。点 **「更多信息」→「仍要运行」**。
3. 安装过程是**一键式**的，装好后桌面会生成快捷方式，双击即可使用。

> 卸载：到「设置 → 应用 → 已安装的应用」里找到 ClipHistory 卸载；卸载不会删除你的剪贴板历史数据（保存在系统 AppData 目录里，见第 9 步）。

## 第 8 步：日常使用说明

### 开机自启（常驻托盘，自动监听）
打开软件 → 点右上角 **⚙️（齿轮）** → 勾选 **「开机自动启动」**。
之后每次开机，软件会自动在后台托盘运行，自动记录你的剪贴板。

### 修改「保存天数」（自动清理）
点 **⚙️ 设置** → 在 **「自动清理留存时长」** 选择 **1 天 / 3 天 / 5 天**。
- 超过这个天数的**普通**记录会被自动删除；
- **置顶**的记录**永远不会被自动清理**；
- 修改后**立即生效**，也会在每小时自动清理一次。

### 搜索
- 顶部搜索框输入关键词，列表**实时过滤**。
- **文本**记录按内容搜索；**图片 / 文件**记录按「备注」搜索。

### 给图片 / 文件加备注（方便以后搜索）
卡片右下角点 **✏️** → 输入备注（比如「购物清单截图」）→ 保存。
之后在搜索框输入「购物清单」就能找到它。

### 重新复制一条记录
**点击任意卡片**，该内容/图片/文件就会被复制回系统剪贴板，直接 `Ctrl+V` 粘贴即可。

### 置顶一条记录
卡片上点 **📌**，它会**固定到列表最顶端**，复制再多的新内容也挤不下去；再点一次取消置顶。

### 删除一条记录
卡片上点 **🗑️** → 按钮变成「确认删除」→ **再点一次**才真正删除（防止误删）。

### 软件常驻后台
窗口右上角 **✕** 只是把窗口藏起来，软件仍在**托盘**（右下角）后台监听剪贴板。要彻底退出：右键托盘图标 → 「退出」。

---

## 第 9 步：数据存在哪里、如何彻底清除

- 所有数据都存在你的电脑本机：
  ```
  C:\Users\你的用户名\AppData\Roaming\ClipHistory\
  ├─ clipboard.db      ← 数据库（所有记录）
  └─ images\           ← 图片记录
  ```
- **彻底清除所有历史**：先托盘「退出」软件，然后删除上面整个 `ClipHistory` 文件夹。下次启动就是全新空记录。

## 常见问题 FAQ

**Q1：`npm start` 后没有窗口，或直接报错、提示 `app` 是 undefined？**
A：极少数电脑的环境变量里被人为设置了 `ELECTRON_RUN_AS_NODE=1`，会让 Electron 以「纯文本模式」运行。解决办法：打开「系统设置 → 高级系统设置 → 环境变量」，在「用户变量」和「系统变量」里找到 `ELECTRON_RUN_AS_NODE`，**删除它**，然后重新打开命令行再试。正常电脑没有这个变量，可跳过。

**Q2：安装包双击后提示「Windows 已保护你的电脑」？**
A：软件没有微软签名，属于正常提示。点「更多信息 → 仍要运行」即可。源码完全开源、纯本地运行，可以放心。

**Q3：杀毒软件报警？**
A：软件**没有任何网络功能**、不联网，可能是杀毒软件对新程序的误报。可以把它加入白名单（信任列表）。

**Q4：`npm install` 或 `npm run dist` 下载特别慢 / 卡住？**
A：项目已配置国内镜像（`.npmrc`）。如果仍然慢，检查网络，或换用手机热点试试。实在不行，把 `npm install` 多执行几次（它会断点续传）。

**Q5：安装时出现 `npm warn Unknown project config "electron_mirror"`？**
A：这是新版 npm 对非标准配置的正常提醒，**不影响任何功能**，忽略即可。

**Q6：我改了留存天数，但旧记录还在？**
A：修改后会立即清理一次；如果还没到点，最迟每小时自动清理一次，或重启软件。**置顶记录本身不会被清理**，请检查是否置顶了。

**Q7：这个软件会联网上传我的剪贴板数据吗？**
A：**绝对不会。** 代码中没有任何网络请求；界面还设置了「内容安全策略」禁止加载任何远程内容。所有数据只写入本机 `AppData` 目录。你可以关闭 WiFi 使用，功能不受任何影响。

**Q8：托盘图标不见了 / 想重新打开主窗口？**
A：托盘图标在屏幕右下角（可能需要点向上的小箭头展开）。如果真不见了，重新运行一次软件；双击托盘图标或右键选「打开主界面」即可。

**Q9：能同时开两个窗口吗？**
A：不能。软件设计了「单实例」保护：再启动一次只会把已运行的窗口唤到前台，避免重复监听和重复写数据库。

**Q10：可以自己改代码吗？**
A：可以。项目结构很简单，每个文件都有中文注释。核心文件：
- `src/clipboard-monitor.js`：剪贴板监听（轮询间隔默认 800ms）
- `src/store.js`：业务逻辑（去重、清理规则）
- `src/db.js`：数据存储
- `renderer/index.html` / `renderer/style.css`：界面
改完用 `npm start` 预览、`npm run dist` 重新打包。

**Q11：打包时报错 `winCodeSign` / `Cannot create symbolic link` / `没有所需的特权`？**
A：这是 Windows 权限问题：打包要用的 `winCodeSign` 工具包内含 macOS 系统的链接文件，解压时需要「创建符号链接」的权限，非管理员默认没有。解决办法：**开启 Windows「开发者模式」**：
1. 双击项目里的 `scripts\开启开发者模式.bat`，在弹出的 UAC 确认框点「是」（最简单）；
2. 或手动开启：设置 → 隐私和安全性 → 开发者选项 → 打开「开发人员模式」。
开启后重新 `npm run dist` 即可。

**Q12：软件图标在哪改？**
A：图标已统一配置为蓝色剪贴板图标，文件位置：
- `build\icons\icon.ico`：应用本体 / 桌面快捷方式 / 窗口 / 任务栏图标（内置 16/32/48/256 多分辨率）
- `build\tray-icon.png`：右下角托盘图标
想换自己的图标：做一张 256×256 的 PNG，运行 `node scripts\gen-icons.js` 会自动重新生成全部图标（含多分辨率 ico）；也可以直接替换上面两个文件后重新打包。

**Q13：更新打包后，桌面快捷方式 / 任务栏图标还是旧的（不刷新）？**
A：Windows 会缓存图标。按下面步骤清理（换新图标后再打包时建议执行）：
1. 先卸载旧版本：设置 → 应用 → 已安装的应用 → ClipHistory → 卸载；
2. 清理打包缓存：打开文件夹 `%LocalAppData%\electron-builder\Cache`，删除里面的 `winCodeSign`、`nsis` 等子文件夹（下次打包会自动重新下载干净的）；
3. 清理 Windows 图标缓存：
   - 按 `Win+R` 输入 `%LocalAppData%` 回车，删除 `IconCache.db`；
   - 再打开 `%LocalAppData%\Microsoft\Windows\Explorer\`，删除里面所有 `iconcache_*.db`；
4. 重启资源管理器：任务管理器 → 找到「Windows 资源管理器」→ 右键 →「重新启动」；
5. 重新 `npm run dist` 打包并安装。
> 若桌面快捷方式仍是旧图标：删除该快捷方式，重新从安装目录发送到桌面即可。
